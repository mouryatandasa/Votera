# VOTERA 

AI-powered Election Education Platform that helps citizens understand elections, voting process, schedules, and results through an intelligent assistant.

## Live Modules

- User Authentication
- Dashboard
- Election Listings
- AI Chat Assistant
- Notifications
- User Profile

## Tech Stack

### Frontend
- React
- Vite
- TypeScript
- TanStack Router
- Tailwind CSS

### Backend
- FastAPI
- Python
- PostgreSQL
- JWT Authentication
- WebSockets

## Folder Structure

frontend/ -> React App  
backend/ -> FastAPI APIs

## Run Locally

### Frontend

cd frontend  
npm install  
npm run dev

### Backend

cd backend  
pip install -r requirements.txt  
uvicorn app.main:app --reload
